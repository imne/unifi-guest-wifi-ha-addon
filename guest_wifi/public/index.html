Guest WiFi

Guest WiFi Manager

Create temporary access tokens for your guest WiFi.

Check the add-on's configuration

Open the add-on in Home Assistant (Settings → Add-ons → Guest WiFi Manager), fix it on the Configuration tab, save and restart the add-on.

Connect your router

Guest tokens are created on your UniFi console. Enter its address and an API key (UniFi Network → Settings → Control Plane → Integrations → Create API Key).
